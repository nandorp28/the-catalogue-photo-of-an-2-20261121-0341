A studio catalogue photograph of a can of **DEHYDRATED WATER** — "JUST ADD WATER" — rendered procedurally in pure Python stdlib. The brushed-silver tin is the hero on a clean light-grey studio sweep, lit by a soft top-left key light, with exactly one accessory sharpening the joke: a small glass of water standing beside it. The label does all the talking: "NET WT 0 G", "INGREDIENTS: WATER (REMOVED)", "100% NOTHING INSIDE", "SERVES 0". No image libraries, no network — the backdrop gradients, metallic cylinder shading, soft floor shadows, glass of water and the bitmap label font are all drawn pixel by pixel by `main.py`, which writes its own PNG with a hand-rolled zlib encoder.

## Run it

```sh
python3 main.py
```

It writes `/output/entry.png` (1024×1024, well under 1 MiB).
